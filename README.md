# 宝宝使用说明书

一款以宝宝成长时间为主线的中文静态网页指南，适合部署到 GitHub Pages。

## 功能

- 根据宝宝出生日期自动生成从出生到3岁的具体时间轴。
- 每次打开时按本机日期更新宝宝月龄、当前时间节点和下一节点。
- 支持自定义宝宝生日、称呼与性别，资料仅保存在当前浏览器。
- 可选择女宝宝或男宝宝，自动适配默认称呼、页面图标与对应私处护理提示。
- 勾选记录按宝宝生日分别保存在本机，不上传服务器。
- 支持导出／导入当前宝宝的 JSON 备份，便于换设备迁移；导入前会校验并请求确认。
- 包含疫苗、行为习惯、饮食与营养补充等重点事项。
- 包含国产/进口疫苗对比及广州参考预算计算器。
- **儿保检查提醒**：按《国家基本公共卫生服务规范（第三版）》标记满月、3/6/8/12/18/24/30/36月龄共 9 个儿保日，卡片内列出检查项目与预约提示；可用“🩺 儿保检查日”筛选，顶部卡片倒计时下一次儿保。
- **儿保指南**：体检时间表、发育里程碑观察点（大运动/精细动作/语言/社交）、常见问题解答。
- **生长记录工具**：录入体重、身长、头围后自动绘制趋势图（悬停查看数值），记录保存在本机并随备份导出导入。
- 无框架、无构建步骤、无第三方前端依赖。

## 本地使用

直接用浏览器打开 `index.html`。

## 备份与迁移

1. 展开页面顶部的“自定义宝宝信息”，点击 **导出当前记录**，保存 JSON 文件。
2. 将文件传到新手机或新电脑。
3. 在新设备的同一页面点击 **导入记录**，核对宝宝资料并确认。

备份包含当前宝宝的生日、性别、称呼、勾选记录和生长记录，不包含预算计算器的临时选择。旧版本备份（无生长记录）可正常导入。导入会覆盖本机同生日的记录，其他生日记录不受影响；无法识别的旧版事项会被忽略并提示。备份文件含宝宝资料，请通过可信方式传输并妥善保管。

## 部署到 GitHub Pages

1. 在 GitHub 创建一个新的公开或私有仓库，例如 `baby-guide`。
2. 将以下文件上传到仓库根目录：
   - `index.html`
   - `styles.css`
   - `script.js`
3. 打开仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**。
5. 选择 `main` 分支和 `/ (root)` 目录，保存。
6. 部署完成后，通过以下地址访问：

   `https://你的GitHub用户名.github.io/仓库名/`

GitHub Pages 公开仓库对应的网站内容会被公开访问，请不要在页面或代码中放入宝宝真实姓名、详细住址、就诊医院、证件号等隐私信息。

## 分享前检查

- 默认资料已脱敏为匿名示例：生日 `2026-01-01`、称呼“宝宝”。其他家庭可在页面顶部点击“自定义宝宝信息”修改性别、生日与称呼。
- 公开部署前仍应检查代码与提交历史中是否含有真实姓名、准确生日、详细住址、就诊医院或证件号等隐私信息。
- 疫苗价格仅用于预算，实际以当地接种门诊公示为准。
- 疫苗程序和健康资料具有版本时效，更新内容时应同步修改页面中的资料核对日期与来源。
- 本指南不替代儿科医生、儿保医生或接种门诊的专业意见。
